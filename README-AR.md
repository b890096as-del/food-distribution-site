# موقع توزيع المواد الغذائية والرعاية والطحين

هذه نسخة أولية قابلة للتشغيل محلياً، وليست منشورة على الإنترنت بعد.

## المتطلبات
- Node.js إصدار 20 أو أحدث.
- استضافة تدعم تشغيل تطبيق Node.js وحفظ ملف قاعدة البيانات `data.sqlite` بشكل دائم.
- HTTPS عند النشر.

## التشغيل
1. فك ضغط المشروع.
2. افتح الطرفية داخل مجلد المشروع وشغّل: `npm install`
3. عيّن متغيرات البيئة الموجودة في `.env.example` في بيئة التشغيل:
   - `ADMIN_USERNAME`: اسم مستخدم الإدارة.
   - `ADMIN_PASSWORD`: كلمة مرور قوية وفريدة.
   - `SESSION_SECRET`: قيمة عشوائية طويلة وسرية.
4. شغّل: `npm start`
5. افتح الموقع على المنفذ المحدد. لوحة الإدارة من `/admin`.

## أعمدة Excel
يجب أن يحتوي الصف الأول على الأعمدة التالية بالأسماء نفسها:
- الاسم الثلاثي
- العدد في الحصة الغذائية
- العدد في الرعاية الاجتماعية
- العدد في حصة الطحين
- تاريخ القائمة
- رقم البطاقة

يقبل الاستيراد أيضاً أسماء بديلة موضحة داخل الكود. يُفضّل تجربة ملف صغير أولاً والاحتفاظ بنسخة احتياطية.

## تنبيه مهم للخصوصية والأمان
- رقم البطاقة لا يُرسل إلى واجهة البحث العامة، لكنه محفوظ في قاعدة البيانات ويظهر للمسؤول بعد تسجيل الدخول.
- البحث الجزئي بالاسم يجعل بيانات النتائج العامة قابلة للاكتشاف؛ لا ترفع بيانات حقيقية قبل التأكد من وجود صلاحية قانونية لمشاركتها والحصول على الموافقات اللازمة.
- هذه نقطة انطلاق تقنية وليست تدقيقاً أمنياً أو نظاماً جاهزاً لاستضافة بيانات حساسة. قبل النشر الفعلي يلزم إعداد HTTPS، تخزين جلسات دائم وآمن، نسخ احتياطي مشفر، حماية CSRF، سياسات وصول ومراجعة أمنية، وتجربة الاستيراد.
- استخدم استضافة لا تمسح قاعدة SQLite عند إعادة التشغيل، أو انقل قاعدة البيانات إلى خدمة قاعدة بيانات مُدارة.
